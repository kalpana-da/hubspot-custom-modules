# HubSpot Service Cards Module

A reusable and fully responsive **HubSpot CMS module** built with **HubL, HTML, CSS, and dynamic custom fields**. The module allows marketers to customize content, typography, colors, and layouts directly from the HubSpot editor without writing code.

## Preview

![Service Cards Module](service_card_module_screenshot%20.jpg)

## Features

- Responsive 2-column and 3-column layouts
- Equal-height service cards
- Dynamic Style tab controls
- Custom typography controls
- Section, card, and tag color settings
- HubSpot SVG icon support
- PNG/WebP image icon support
- Dynamic SVG hover color
- White hover effect for image icons
- Mobile and tablet optimized
- Repeater fields for unlimited service cards

## Technologies Used

- HubSpot CMS
- HubL
- HTML5
- CSS3
- JavaScript
