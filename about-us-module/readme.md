# About Us HubSpot Custom Module

A fully reusable **HubSpot CMS custom module** for creating a modern **About Us / What We Serve** section with a responsive image layout, service cards, and editable style controls.

## Preview

![About Us Module](https://raw.githubusercontent.com/kalpana-da/hubspot-custom-modules/main/about-us-module/about_us_module_screenshot.jpg)

## Features

- Responsive two-column layout
- Editable section heading and subheading
- Rich text description
- Left-side featured image
- Repeater for unlimited service cards
- Icon, title, and description for each card
- Complete style controls from the HubSpot editor
- Mobile and tablet optimized
- Ready to import into any HubSpot account

## Installation

1. Open **HubSpot Design Manager**.
2. Upload the `about-us-module` folder.
3. Publish the module.
4. Drag the module onto any page.
5. Customize content and styles directly from the page editor.
